# Вкладка «Навигатор» (задача #66)

Четвёртая вертикальная вкладка панели `XDATAPALETTE`. Она показывает объекты пространства модели активного
чертежа с данными `BobrovXDATA` деревом, построенным по выражению профиля, и колонки со значениями
параметров. Вкладка только читает чертёж: XDATA, схему и объекты она не меняет. Фильтры, редактор дерева,
правка XDATA и новый движок формул в задачу не входят.

## Слои

| Слой | Классы | Что делает |
| --- | --- | --- |
| Core (без AutoCAD и WPF) | `NavigatorTreeExpression`, `NavigatorValueSource`, `NavigatorObject` | разбор выражения и источников значений, вычисление значений объекта |
| | `NavigatorTreeBuilder`, `NavigatorTree`, `NavigatorNode` | построение дерева, группы «Не задано» и «#ОШИБКА», автогруппы |
| | `NavigatorProfile`, `NavigatorSettings`, `NavigatorProfileStore` | профили и настройки, JSON, безопасная запись |
| | `NavigatorViewModel`, `NavigatorProfileEditor` | состояние вкладки, колонки, сортировка, профили |
| | `INavigatorSource`, `NavigatorSnapshot`, `NavigatorReadState` | граница с AutoCAD, учёт прочитанных и изменённых объектов |
| UI (WPF) | `NavigatorView`, `NavigatorProfileWindow` | многоколоночное дерево и окно настройки профиля |
| AutoCAD | `AutoCadNavigatorSource`, `AutoCadPaletteHost` | чтение пространства модели, события, выбор и показ объекта |

`XDataParser`, `XDataV2`, `XDataWriter`, `XDataPatchV2`, `CalculatedStrings`, `FormulaExpressions`,
`ObjectValuesCache`, `SchemaCache`, `SelectionController`, `SelectionViewModel` и `PropertyGrid` не изменены.
Навигатор использует их через адаптеры: снимки читает `AutoCadDataReader`, значения берутся из
`ObjectValuesCache` документа, формулы считает `ObjectCalculation` (как в VST).

## Выражение дерева

Пример профиля «Электрооборудование» (как в ZCAD):

```
-DB_link|-DESC_MountingParts|+NMO_BaseName|+NMO_Suffix|-@@[NMO_Name]
```

- Части разделяются `|`. Внутри `@@[…]` символ `|` разделителем не считается.
- `+` включает часть, `-` выключает её: выключенная часть пропускается. Часть без знака — ошибка выражения
  (в отличие от ZCAD, где это молча допускается), профиль с ошибкой не применяется.
- Включённые части, кроме последней части выражения, — уровни групп. Последняя часть даёт имя листа; если она
  выключена или пуста, лист называется по типу объекта на языке AutoCAD («Блок», «Отрезок»).
- Источник части или колонки: id параметра (`NMO_BaseName`), формат `CalculatedString` (`@@[NMO_Name]`,
  `@@[A]-@@[B]`) или формула NCalc (`=@@[Power]*2`, задача #43). Значения вычисляются теми же правилами,
  что в VST: формулы схемы, `Enum` — подписью, `Double` — с `Editor.Precision`, `Boolean` — «Да»/«Нет»;
  затем значения объекта, атрибуты блока и геометрия.

Для выражения выше: группы — `NMO_BaseName`, затем `NMO_Suffix`; листы — без имени (тип объекта), так как
`@@[NMO_Name]` выключен. Для `+NMO_BaseName|+@@[NMO_Name]` листы называются значением `NMO_Name`.

Пограничные случаи:

| Случай | Результат |
| --- | --- |
| параметра нет у объекта или значение — пустая строка | объект в группе «Не задано» (текст задаётся `emptyText` в `navigator.json`) |
| параметр не найден в схеме чертежа | объект в группе «Не задано», над деревом — предупреждение с id параметра |
| ошибка формулы или формата | объект в группе «#ОШИБКА», красным, текст ошибки во всплывающей подсказке |
| исключение при обработке одного объекта | этот объект — лист с ошибкой; остальные объекты не затронуты |
| объект не прочитан из чертежа | он не показан; строка состояния: «не прочитано объектов: N» |
| одинаковое значение группы у нескольких объектов | одна общая группа |
| одинаковые имена листов под одной группой | автогруппа с этим именем (ZCAD `TNMAutoGroup`) |

Группы — значения выражения, а не объекты AutoCAD; у группы есть только число объектов. Лист хранит только
handle объекта. Группы сортируются естественным порядком («Щ2» раньше «Щ10»), «Не задано» и «#ОШИБКА» — в конце.

## Колонки

Колонка профиля — `id`, `caption`, `value` (источник, как часть выражения), `width` (16–2000) и `visible`.
Первая колонка «Объект» — дерево; её ширина хранится в `navigator.json` (`treeWidth`).

- Ширина меняется перетаскиванием границы заголовка, порядок — перетаскиванием заголовка.
- Щелчок по заголовку сортирует по колонке, повторный щелчок меняет направление. Сортировка по «Объект»
  сортирует группы и листы, сортировка по колонке сортирует листы внутри групп; группы остаются впереди.
  Колонка и направление сортировки хранятся в `navigator.json`.
- Контекстное меню заголовка скрывает и показывает колонки.
- Изменения ширины, порядка и видимости отмечают профиль изменённым: кнопка `✓` и пункт «Сохранить» меню `⚙`
  записывают его. При переключении на другой профиль панель спрашивает, сохранить ли изменения.

## Профили

```
%APPDATA%\AcadPaletteSetXData\navigator\navigator.json         активный профиль, emptyText, treeWidth, сортировка
%APPDATA%\AcadPaletteSetXData\navigator\profiles\<id>.json      один профиль
```

Примеры: [examples/navigator/](../examples/navigator/) (`navigator.json`, `profiles/electrical.json`,
`profiles/by-phase.json`) и схема для них [examples/navigator-schema.json](../examples/navigator-schema.json).

```json
{
  "version": 1,
  "id": "electrical",
  "name": "Электрооборудование",
  "tree": { "expression": "-DB_link|-DESC_MountingParts|+NMO_BaseName|+NMO_Suffix|-@@[NMO_Name]" },
  "columns": [
    { "id": "name", "caption": "Наименование", "value": "@@[NMO_Name]", "width": 160, "visible": true },
    { "id": "power", "caption": "Мощность", "value": "Power", "width": 90, "visible": true }
  ]
}
```

- `id` — имя файла: латинские буквы, цифры, `_` и `-`, не длиннее 64 символов. Неизвестные поля JSON сохраняются
  при перезаписи.
- Нет папки или файлов — используется встроенный профиль «Электрооборудование»; файлы появятся при первом сохранении.
- Верхняя панель вкладки: список профилей, `⟳` «Обновить», `⊞`/`⊟`, `✓` «Сохранить» и `⚙` с пунктами
  «Настроить профиль…», «Новый профиль…», «Удалить профиль…», «Сохранить».
- «Настроить профиль…» открывает окно: название, выражение дерева с проверкой по схеме чертежа и таблица
  колонок (добавить, удалить, переместить, ширина, видимость). Переименование меняет только `name`, файл остаётся.
- «Новый профиль…» копирует активный профиль под свободным id `profileN`. «Удалить профиль…» удаляет файл
  после подтверждения и переключает на первый оставшийся профиль.
- Переключение в списке применяется без перезапуска: файл профиля читается заново, JSON, выражение и колонки
  проверяются, дерево строится из уже прочитанных объектов (чертёж заново не читается, вычисленные значения
  переиспользуются).
- Повреждённый или неверный файл не применяется: остаётся последний действующий профиль, над деревом —
  сообщение с путём файла и ошибкой; файл не перезаписывается. Повреждённый `navigator.json` заменяется
  настройками по умолчанию в памяти, тоже с сообщением.
- Запись безопасна: текст пишется в `<файл>.tmp`, затем заменяет файл (`File.Replace`). При ошибке временный
  файл удаляется, прежний файл не меняется.

## Работа в AutoCAD

- **Чтение.** Только активный документ, только сущности пространства модели с XDATA `BobrovXDATA`, только
  `OpenMode.ForRead` под `LockDocument` и `StartOpenCloseTransaction` в потоке интерфейса. Снимки читает
  `AutoCadDataReader`, значения — общий с VST `ObjectValuesCache` документа, схема — `SchemaCache` документа.
- **Кэш на документ.** У каждого открытого документа свой список прочитанных объектов (`NavigatorReadState`).
  Первое чтение читает всё пространство модели. Далее события базы (`ObjectAppended`, `ObjectModified`,
  `ObjectErased`, `ObjectReappended`, `ObjectUnappended`) только запоминают id. Следующее чтение открывает лишь
  изменённые объекты; для изменённых XRecord и словарей ищется владелец в пространстве модели.
  Полное чтение — после `U`/`UNDO`/`REDO`/`MREDO`, при смене пространства модели, если изменилось больше 2000
  вложенных объектов, после прерванного чтения и по кнопке `⟳`.
- **Когда обновляется.** Изменения чертежа, конец или отмена команды, Undo/Redo, переключение документов,
  закрытие документа и смена схемы планируют одно обновление в `Application.Idle`, когда редактор свободен.
  Скрытая вкладка или панель чертёж не читает: изменения копятся и читаются один раз при показе вкладки.
  На события выделения навигатор не подписан.
- **Выбор.** Щелчок по листу выделяет объект: `Editor.SetImpliedSelection` по handle, без показа. Двойной щелчок
  или Enter также показывают объект (масштаб по его границам с полями, при необходимости переход на вкладку
  «Модель»). Группа ничего не выделяет: щелчок выбирает строку, двойной щелчок и Enter разворачивают группу.
  Если объект удалён, над деревом появляется сообщение «не найден в чертеже (удалён?)»; если идёт команда —
  «Выполняется команда…».
- **Закрытие.** При закрытии документа его кэш и подписки освобождаются, вкладка переходит к следующему
  документу или пустеет. При завершении AutoCAD навигатор отписывается от всех событий и сохраняет
  несохранённые настройки (`navigator.json`).
- **Темы.** Вкладка и окно профиля используют словари тем панели: `COLORTHEME=0` — тёмная, `1` — светлая,
  в том числе при смене темы открытой панели.
- **Трассировка.** При `XDATAPALETTE_TRACE=1` (переменная окружения до запуска AutoCAD) после каждого чтения
  выводится строка вида
  `[XDATAPALETTE] Навигатор: частичное чтение, просмотрено 3, объектов BobrovXDATA 1000, ошибок 0; 4 мс; кэш значений 1000, разборов XDATA 1003.`
  и сообщения о выборе объектов.

## Проверка

- Unit-тесты Core: `NavigatorTests` (выражение, источники значений, все случаи таблицы выше, автогруппы,
  сортировка, профили и их файлы, безопасная запись, переключение без перечитывания, колонки) и
  `NavigatorReadStateTests` (первое, частичное и полное чтение, Undo, прерванное чтение).
- WPF-смоук `VerifyNavigator` (`experiments/AcadPaletteSetXData.WpfSmoke`) на net48 и .NET 8 отображает
  настоящие `PaletteView`/`NavigatorView` и `NavigatorProfileWindow` в обеих темах. Он проверяет дерево,
  колонки и их меню, сортировку, переключение и создание профиля, выбор листа и группы, чтение только
  показанной вкладкой и сохраняет рендеры `issue66-*.png` — [docs/screenshots](screenshots/README.md#задача-66-вкладка-навигатор).
- Нативное поведение в AutoCAD (события, Idle, выбор и показ) CI не проверяет — сценарий в
  [autocad-verification.md](autocad-verification.md#задача-66-вкладка-навигатор).
