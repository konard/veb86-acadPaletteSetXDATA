# Проверка этапов 1–3 в AutoCAD 2021

Автоматическая сборка использует реальные API Autodesk, а WPF smoke-проверки
работают на Windows для .NET Framework 4.8 и .NET 8 без AutoCAD.
Следующие действия требуют установленного AutoCAD; CI не подтверждает их выполнение.

Основная цель — AutoCAD 2021 (сборка `net48`, API 24.0.0). Дополнительные цели:
AutoCAD 2024 с явно выбранным API 24.3.0 и AutoCAD 2025 (`net8.0-windows`).
Записывайте точную версию AutoCAD и обновления.

1. Скопируйте три DLL плагина в доверенную папку, загрузите через `NETLOAD`.
   Панель не должна открываться автоматически.
2. Выполните `XDATAPALETTE`. Проверьте наличие одной панели «Свойства XDATA»,
   вертикальные вкладки справа: «Свойства», «XDATA», «Команды».
3. Выберите каждую вкладку мышью и клавиатурой. Без выделения «Свойства» неактивна,
   «XDATA» показывает пустое дерево, «Команды» — справку; сверху предложение выбрать объекты.
4. Повторно выполните команду: панель скрывается. Ещё раз: открывается та же панель,
   вкладка сохраняется. Повторите после закрытия нативной кнопкой ×.
5. Перетащите панель к левому и правому краям AutoCAD. Проверьте закрепление,
   переход в плавающее окно, изменение размеров и сворачивание кнопкой автоскрытия.
6. Установите `COLORTHEME=1`, затем `COLORTHEME=0`: нативная рамка и WPF-содержимое
   должны следовать теме. Текст и вкладки читаемы, выбранная вкладка не сбрасывается.
   Повторите смену темы со скрытой панелью, затем покажите её командой.
7. Откройте вторую DWG, переключитесь между документами и закройте их. Команда
   должна управлять той же панелью; данные чертежей не меняются.
8. В **новой** DWG через `APPLOAD` загрузите `examples/stage3-selection.lsp`,
   выполните `XDATASTAGE3SAMPLE`. Пример создаёт LINE с ESMT XDATA и LWPOLYLINE
   с SMARTLINE XDATA и XML XRecord, устанавливает `PICKFIRST=1` и выделяет оба объекта.
9. Сверху должно быть «Выделено объектов: 2». Выберите LINE в списке объектов:
   «Название» = `Line A`, «Номер» = `021`, материал `CD35`, количество `1,2`, флаг включён.
   Выберите LWPOLYLINE: «Название» = `Cable B`, номер `022`, материал `CD35`,
   количество `2`, флаг выключен. Параметры просматриваются отдельно, без «Разное».
10. Во вкладке «XDATA» проверьте RegApp, коды 1000/1002, вложенный Material,
    ветку ExtensionDictionary / XRecord, ключ SMARTLINE и XML-элементы/атрибуты.
    Раскройте/сверните ветки. Повторите смену объекта в этой вкладке.
11. Выделите каждый примитив мышью отдельно, добавляйте/удаляйте из набора Shift,
    выделите рамкой, нажмите Esc. Данные обновляются после завершения выбора;
    пустой набор очищает поля/материалы/дерево и отключает редактор.
12. Выделите объект без XDATA: поля пустые, нет материалов предыдущего объекта.
    Дополнительно проверьте динамический блок с XDATA на самом BlockReference:
    читаются данные экземпляра, а не определения блока.
13. При открытой панели создайте/активируйте вторую DWG, выберите другой объект,
    закройте активную DWG, затем все чертежи. Старая DWG не должна оставаться в панели.
    Выделение в неактивном документе не должно менять текущие параметры.
14. До первого вызова `XDATAPALETTE` выберите примитив: уже существующее выделение
    загружается. Повторите выбор со скрытой панелью и откройте её снова.
15. Проверьте режим чтения: поле названия/номера/проекта не меняется с клавиатуры;
    тип, флаг, `+ Добавить`, `✎`, `×` отключены. Раскрытие секций и копирование текста доступны.
    Состояние `DBMOD` до/после просмотра должно совпадать. Сам пример из п. 8 изменяет DWG.
16. Через сторонний инструмент измените XDATA, выполните Undo/Redo при том же выделении:
    после завершения команды панель заново читает данные. Проверьте неизвестный RegApp,
    неизвестные поля и повреждённый XML — сырые значения видны, предупреждение в «XDATA».
17. Смените темы, вкладки, скройте/откройте панель. Выбранный объект/вкладка сохраняются.
    Уменьшите панель до 280×320: поля, дерево и примечания доступны с прокруткой.
18. Закройте AutoCAD. Не должно появляться ошибок освобождения панели/подписок.

Сравнение «Разное», групповая запись и Undo/Redo записи относятся к этапам 4–5 ТЗ.
WPF-рендеры показывают содержимое панели отдельно от нативной рамки AutoCAD.
